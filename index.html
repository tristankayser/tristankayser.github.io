I grew up in Windhoek, Namibia, and now live in Eislingen/Fils near Stuttgart. I'm training as a Fachinformatiker für Systemintegration — an IT systems integration specialist — and since September 2026 I'm in my second training year at IT-Works GmbH in Uhingen.

My first year at netplay GmbH put me straight into client work: Proxmox servers and backups, OPNsense firewalls, Windows rollouts, patch automation and the daily support queue. At home I run a three-node Proxmox lab where I try things out before I'd ever touch them on a production system.

Before IT I competed in artistic gymnastics at Level 8 and coached kids in Windhoek. I still fly drones and enjoy taking old hardware apart to see how it works.

#04 Projects

Six things I built or fixed, written the way an IHK project report is structured: starting point, what I did, result.

Work

Central Windows patching with AWX

Nov 2025 – Mar 2026

Starting point

Windows 11 clients and VMs were updated by hand, one machine at a time — slow, and easy to forget one.

What I did

Installed AWX (the web UI for Ansible), built inventories, connected Windows hosts over WinRM and wrote job templates and playbooks. Tested everything in a lab before rolling it out.

Result

Updates for several Windows machines run from one place, repeatably and with a log of every run.

  • Ansible
  • AWX
  • WinRM
  • Windows 11
Work

Infrastructure documentation for two client sites

May 2026

Starting point

Two small-business clients had no complete, current documentation of their servers and network.

What I did

Collected data read-only from production Proxmox (qm, pvesm, pvesh) and OPNsense: VMs, IPs, storage, VPN, DHCP leases, firewall and NAT rules. Turned it into structured Excel, PDF and JSON files.

Result

Handover-ready documentation for both sites. On the way I found a full swap partition and a VM on a disabled storage and reported both.

  • Proxmox VE
  • OPNsense
  • WireGuard
  • Python
  • Excel / PDF / JSON
Lab

Active Directory lab on VMware ESXi

Jul 2026

Starting point

I wanted to understand Windows domains properly before working on them at a client.

What I did

Built a domain controller on Windows Server 2025 with OUs and groups, file shares with share and NTFS permissions, GPO drive mappings, and an OPNsense VM for DHCP and DNS — isolated on its own vSwitches.

Result

A reproducible lab I can reset any time. Key lesson: when share and NTFS rights meet, the more restrictive one wins.

  • ESXi 8
  • Windows Server 2025
  • AD DS
  • GPO
  • OPNsense
Homelab

Local AI stack on old server hardware

2026

Starting point

I wanted private AI tools at home — on a Xeon without AVX2 and no big GPU.

What I did

Built a dedicated LLM VM with llama.cpp behind llama-swap (eight models), LibreChat as the front end with SearXNG web search, and a Hermes Agent reachable via WhatsApp. Tuned flash attention, mlock and a quantised KV cache, and fixed a disk layout that left most of the disk unused.

Result

Stable 7–8 tokens per second on CPU, fully local, no cloud dependency.

  • Proxmox
  • llama.cpp
  • llama-swap
  • LibreChat
  • SearXNG
  • Docker
